# Internal skills

Engineering skills for the Bluejay team, in a plugin of their own.

They are deliberately **not** listed in `.claude-plugin/marketplace.json`. That file is what
`/plugin marketplace add bluejay-ai-dev/bluejay-skills` shows a customer, and these skills name
sandbox organizations, internal repository paths and unreleased branches. Adding an entry for
this plugin publishes all of it.

Install by path:

```
/plugin install bluejay-internal@bluejay-skills
```
